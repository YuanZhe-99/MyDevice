# 版本历史

MyDevice!!!!! 的逐发布摘要。改变行为前理解*为何*存在有用——几个条目记录否则看起来像怪癖的刻意安全修复。

- `v1.4.0`：修复在线设备搜索并刷新捆绑模板目录。**移除 GSMArena**：它对每个请求都返回以 *HTTP 200* 承载的 Cloudflare Turnstile 验证页，因此旧的状态码检查通过，随后行匹配模式失配，`search()` 返回 `[]`——与「没有这台设备」无法区分。纯 HTTP 客户端无法通过该验证。**Notebookcheck 一直可达，却被我们自己的过滤器废掉**：它把标准设备页命名为 `<name> - Reviews and Specs`，而文章过滤器丢弃一切匹配 `review` 的结果，于是 `Galaxy Z Fold8` 和 `Z Fold8 Ultra` 被丢掉，标题较短的旧款 `Z Fold7` 反而留下——过滤器恰好删掉了最新设备。它的详情页还带有完整规格表（Processor/Memory/Display/Storage/Battery/OS/Released），此前从未被读取，只取了 JSON-LD 图片，因此内存、存储、电池、系统和发布日期从该数据源根本没有到达用户。**PhoneDB** 接替 GSMArena 承担手机覆盖，并加了相关性闸门：它的 `filter=`/`model=` 参数被忽略（只有 `search_exp` 的 POST 才真正搜索），而对未收录的型号它会退化为宽松匹配，返回约 120 台无关手机。`search()` 现在返回 `DeviceSearchResponse`，为每个数据源带一个 `DeviceSearchStatus`（`ok`/`blocked`/`unreachable`/`markupChanged`），使机器人验证墙、服务中断和页面结构变化不再一律显示为「未找到结果」；零匹配查询仍判定为 `ok`，通过 `isNotebookcheckSearchPage`/`isPhonedbResultsPage` 识别，因此新信号不会对每台未收录设备虚报警。解析逻辑移入不涉及网络的 `device_search_parsers.dart`，由基于固定样本的测试覆盖；`stripHtml` 现在**解码**实体而非删除（`12&nbsp;GB` 过去会塌缩成 `12GB`）；`tool/check_sources.dart` 用一条命令报告数据源健康状况。模板方面：`device_templates.json` 自 `v0.1.0` 起未曾改动，本次新增 19 台设备（iPhone 17 全系、Galaxy S26 全系、Z Fold7/Fold8/Fold8 Ultra、Z Flip7、Pixel 10 Pro Fold、Xiaomi 17 Pro/Pro Max、Tab S11 Ultra、M5 MacBook），所有规格均从实时数据源抓取而非凭记忆填写。修复四个模板缺陷：`toDevice` 硬编码 `storage.first`，导致多容量模板永远塌缩为最小容量；14 个 VPS 模板对象形态 `cpu` 的详细信息在解析期即被丢弃且无法通过预设查找找回；选择器只搜索 `name`，尽管其列表项显示品牌/CPU/内存；`validate_json.dart` 只检查文件能否解析——现在会检查字段、类型、类别枚举、重复项与排序顺序，并立即查出四个此前无人知晓的重复预设条目。`PRIVACY_POLICY.md` 与应用内隐私页在本次工作之前就已实质失实（声称「不进行其他网络通信」，而应用早已连接 GSMArena、Notebookcheck 和 Startpage），已在四种语言中更正。版本统一为 `1.4.0+38` / MSIX `1.4.0.0` / 安装器 `1.4.0`。
- `v1.5.0`：面向折叠屏、平板和桌面窗口的自适应布局基础——六个发布中的第一个，把每个界面纳入同一套规则，原样采用 MyAnime 在 1.5.2–1.5.6 中推导出的约定。**新的策略模块 `lib/shared/utils/adaptive_layout.dart` 只 import `dart:core`，持有应用做出的每个宽度决策。** 其分栏规则 `canSplitLayout` 是宽高比测试而非宽度断点，原因是 Galaxy Z Fold 8：它展开是 4:3 的*横向*面板，竖屏时就是 3:4，相对高度比它取代的近方形 Fold 7 更窄，同一台设备在同一宽度需要两个答案——宽 ≥ 600、高 ≥ 480 且宽/高 ≥ 0.82 让它横屏双栏、竖屏保持原单列。目前还没有页面分栏；规则先落地，让 1.5.1 的列表和 1.5.2 的详情页门控在已被测试的东西上。**壳从 600 逻辑像素起把导航移到侧边**：由与底栏同一份目的地列表构建的 `NavigationRail`（`groupAlignment: 0`，紧凑高度可滚动），由 `useNavigationRail` 选择——第二条仅宽度的规则，刻意与分栏规则分开——横持手机 915 × 412 不能分栏，却把五分之一高度花在底栏上而 915 dp 宽度闲置，Z Fold 8 竖屏出于同一理由得到导航栏。MyAnime 的底栏避让刻意未移植：MyDevice 的标签页各自在壳之下带自己的 `Scaffold`，页面 body 从不在底栏之下，设备列表的 `bottom: 80` 是给三个浮动操作按钮的避让。**应用原有的三处内联断点全部消失**，各自成为具名谓词，数字在文档注释里有依据：服务概览的指标网格走 `serviceMetricColumns`，与内联规则算术等价，没有任何视口改变；拓扑卡片的 `< 680` 变成同为 680 的 `useTopologyActionsRow`，但卡片现在拿到扣除导航栏后的宽度，所以 Pixel 10 Pro Fold 竖屏把动作堆叠到标题下而以前是并排；财务摘要的 `>= 520 ? 3 : 2` 变成 `financeSummaryColumns`——160 dp 的 `columnCapacity` 下限 2（卡片从未一行一个指标，外屏也不能开始如此），其第三列在 512 而非 520 出现。**两个在线搜索对话框从窗口推导高度**，替代在横持手机或横持折叠外屏上溢出的固定 560 / 480：`dialogBodyHeight` 上下各留 40，有空间时停在旧尺寸（Fold 8 横屏不变），且永不低于 240；宽度封顶在 Material 的 560，也阻止对话框在平板上拉满。Android 清单原本就声明了 `screenLayout|screenSize|smallestScreenSize|density`，折叠展开不重启 activity 就调整窗口，无需其他改动。记录在新的 `doc/en-us/adaptive-layout.md`（含设备表与推理），由每个命名设备几何上的纯函数测试加壳与对话框的渲染测试覆盖，测试以简体中文驱动，因为 `flutter_test` 默认字体把拉丁字形渲染成全角方块。版本统一为 `1.5.0+39` / MSIX `1.5.0.0` / 安装器 `1.5.0`。
- `v1.5.1`：用得上宽屏的列表。窗口一旦通过 1.5.0 的分栏规则，设备、网络、数据集列表以及服务页的设备 / 链路 / 端口视图就以尽可能多的、不小于声明最小宽度的列填满它，最多四列，先左后右再换行——经 `columnCapacity` 实现 Google 的自适应最小宽度信息流指南，绝不按断点硬编码列数。**每种 tile 带自己的最小值，并在文档注释里给出依据**：设备卡 320 dp（头像、间距与尾部铺装占 152，留 168 给二十字名称和两行副标题），网络卡 300（单行“类型 · 子网”副标题），数据集 tile 320（四行存储信息不能折行），服务卡 320。正是这些最小值让同一宽度对不同列表给出不同答案：平板横屏给网络三列而其他两列，Z Fold 7 竖屏让设备列表离第二列差三个逻辑像素而旁边的数据集列表得到两列——这是规则在边界处起作用。`listColumnCount` 把最小值作为参数，是与 MyAnime 版本唯一的差异，因为 MyDevice 有四种 tile 形状。**每个列表记住自己的列数**，存于 `storage_config.json`（`deviceListColumns`、`networkListColumns`、`dataSetListColumns`、`serviceListColumns`），设备本地，因为窗口尺寸是设备而非账号的属性，默认自动——从文件删除而非写成零——窗口缩小时钳制而非改写，所以桌面上设的列数能挺过折叠、展开时回来；应用栏控件在宽度只容一列时隐藏而非禁用，重排模式与服务概览也隐藏——概览是异构滚动流，刻意保持单列。内容宽度是 `shellContentWidth` 减各页自身内边距，导航栏的宽度被扣除。**手势跟随列数**：设备与数据集 tile 一列时保留右滑编辑、左滑删除，多列时去掉，因为在一个窄格子里水平拖动含义不明；尾部 chevron 变成携带同样操作的菜单——服务 tile 早已有的那种——而两页的删除都没有其他入口，正是这个菜单保住了它。行是 `Expanded` 格子组成的 `Row` 而非 `GridView`，所以设备列表保住 `ListView.builder` 虚拟化，服务视图的卡片仍是同一滚动视图的 children；末行不满时补齐空格子让剩余 tile 保持宽度。由每台命名设备上的纯函数测试、偏好往返测试，以及针对种子存储目录在 Z Fold 8 横竖、Pixel 9 横竖和平板上渲染四个列表的测试覆盖，共享测试助手抽到 `test/support/`。版本统一为 `1.5.1+40` / MSIX `1.5.1.0` / 安装器 `1.5.1`。
