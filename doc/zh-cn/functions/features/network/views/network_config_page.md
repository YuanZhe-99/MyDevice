# lib/features/network/views/network_config_page.dart

## 声明

| 声明 | 类型 | 用途 |
|---|---|---|
| `NetworkConfigPage` | 构造函数 | 绑定网络分配至配置原文编辑器。 |
| `createState` | 方法 | 创建编辑状态。 |
| `initState` | 方法 | 填入原文与格式。 |
| `dispose` | 方法 | 释放控制器。 |
| `_file` | 方法 | 读取/导出 UTF-8 文件并显示错误。 |
| `build` | 方法 | 构建格式标签、复制/文件操作及原文编辑器。 |

保存返回网络分配草稿，由调用方持久化。空文本清除配置，仅空白文本保留。格式切换
不转换内容。桌面导出写入选择的路径，移动端向选择器传递字节。取消不写入。
