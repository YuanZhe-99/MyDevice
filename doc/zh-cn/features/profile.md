# 个人资料（名称和头像）

自 1.7.0 起，应用有了一个小小的用户个人资料：**名称**和**头像**。两者都是可选的，都会通过 WebDAV 同步到每台设备，并包含在备份中。逐文件的细节见 [`../functions/features/profile/`](../functions/features/profile/services/profile_store.md)；文件格式见 [`../data-formats.md`](../data-formats.md#profilejson)，同步规则见 [`../sync.md`](../sync.md#个人资料文件)。

## 出现的位置

- **首页（设备列表页）应用栏。**头像以小圆形显示在“MyDevice!!!!!”标题左侧。点击它会打开设置（应用栏按钮的提示文字是*个人资料与设置*）。什么都没设置时显示人像图标；有名称但没有头像时显示名称的首字母。
- **设置页头部。**一个*个人资料*行是设置列表的第一项，位于*通用*之前，因此在单窗格和双窗格布局中都会出现。它显示较大的头像、名称（或占位文字*设置你的名称*）、提示*名称和头像会在你的设备间同步*，以及一个编辑图标。点击它会打开编辑对话框。

## 编辑

编辑对话框（*个人资料*）包含大号头像、*选择头像*按钮、仅在已设置头像时出现的*调整头像*与*移除*按钮，以及*名称*输入框（最多 40 个字符）。点击大号头像可调整当前头像，没有头像时则为选图。

- **头像更改立即保存。***选择头像*会打开平台文件选择器来选一张图片，然后进入头像编辑器（见下）；在编辑器中保存才会存储头像，退出则不存储任何内容。*调整头像*（自 1.7.1 起）用当前头像重新打开编辑器；*移除*会清除头像。若所选文件无法作为图片使用，会弹出提示条*无法使用此图片*，且不会有任何改变。
- **名称在点击保存时保存。**取消会放弃它。名称会去除首尾空白；空名称表示清除，保存未变化的名称不会写入任何内容。

## 头像编辑器（自 1.7.1 起）

选图之后，全屏编辑器用来取景：图片位于**圆形遮罩**之下（头像在各处都显示为圆形），放在 `InteractiveViewer` 中——拖动以移动，双指缩放或滚动鼠标滚轮以 1 倍到 8 倍缩放；图片始终铺满圆形（`boundaryMargin: zero`）。应用栏有**旋转**（顺时针 90 度）、**重置**（居中并铺满圆形）和**保存**，下方有一行提示。保存时把可见的正方形经缩放与平移映射回原图像素，并恰好裁剪这一区域。

## 头像处理

所选图片会被解码，按其 EXIF 方向（以及编辑器的旋转）转正，为编辑器限制最长边不超过 2048 像素，裁剪为用户取景的**正方形**（不经编辑器时为居中正方形），缩放到 **512 x 512** 像素，并以 **JPEG**（质量 88）存为 `images/avatar_<uuid>.jpg`。这一过程在单独的 isolate 中运行，使界面不会卡顿。每个头像都使用全新的文件名。替换或移除头像只会删除该设备上先前的头像文件。已存储的头像本身只有 512 像素，所以再次调整只能进一步放大、旋转或重新居中。

## 同步

个人资料是第五个同步的数据模块（`profile.json`）。每个字段都有自己的时间戳，按后写者胜合并，因此在一台设备上改名称、在另一台设备上改头像，两者都会保留；永远不会出现冲突对话框。头像图片与设备图片一起经由添加式图像阶段传输。由于图像同步从不覆盖也从不删除，旧头像文件会留在 WebDAV 服务器和其他设备上——这是已知限制。1.7.0 之前的构建从不请求该文件，每次同步多一次 `GET profile.json`。备份包含 `profile.json`（恢复时的标签为*个人资料*）和头像文件，ZIP 导出同样包含两者。见 [`../sync.md`](../sync.md#个人资料文件) 和 [`../backup-restore.md`](../backup-restore.md)。

## 行为说明

- 在另一台设备上编辑的个人资料无需重启即可出现：每当同步或恢复重写本地数据，个人资料状态就会重新加载。
- 如果头像文件尚未到达本设备，则显示占位图，直到它到达。
