# Device thumbnail sources

Every PNG here is a derivative of a photograph or render, freely licensed unless its row says
otherwise. Each one was produced with
`dart run tool/prepare_device_image.dart <source> <output.png>`, which removes the plain
background (or, with `--roundrect`, masks a tightly cropped phone), trims to the device, and fits
it inside the avatar circle on a transparent 256 px canvas; `--crop` first picks one region of a
larger source. `tool/validate_json.dart` checks that the result is transparent and circle-safe.

Since 1.6.0 some rows are **not freely licensed**: ASUS NUC product renders, and manufacturer
product images supplied by the repository owner (Razer Blade 14, Intel NUC 11, Galaxy Z Fold6 and
Fold8, AirPods 4, iPad Pro, Surface Laptop 7). They name the copyright
holder so they can be replaced when a free image turns up.

Derivatives keep the original license. "Shows" names what the photo actually depicts when one
image serves several near-identical templates.
