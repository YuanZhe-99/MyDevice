# lib/features/network/views/tailscale_import_page.dart

## 声明

| 声明 | 类型 | 用途 |
|---|---|---|
| `TailscaleImportPage` | 构造函数 | 绑定解析行、目标网络及设备快照。 |
| `createState` | 方法 | 创建预览状态。 |
| `initState` | 方法 | 建议唯一节点 ID/名称匹配，其他行默认跳过。 |
| `_save` | 方法 | 重新验证设备，创建所选新设备并批量保存分配。 |
| `build` | 方法 | 构建逐行选项、原始详情、数量及错误。 |
| `_matchLabel` | 方法 | 解释初始匹配及候选歧义。 |
| `_oldValue` | 方法 | 读取修改预览中的已有网络分配值。 |

保存前不写入。重复目标设备、已删除网络及退役目标拒绝保存。重新读取设备避免覆盖
已有规格。预览内保留新 ID 供重试。网络一次排队原子写入，但设备与网络不是跨文件
事务；网络失败时已保存新设备可能保留。失败时预览继续打开。

预览先尝试节点 ID、精确名称及唯一规范化名称匹配，再请用户核对。每行展示匹配
依据，可调整目标设备、新设备名称/分类/系统，并逐字段勾选，显示修改前后值。
未勾选字段保留当前网络分配值及原始 CSV 列。节点 ID 始终标识导入分配。保存前
展示重复目标和节点 ID；预览后的并发修改会拒绝保存，要求重新载入。
