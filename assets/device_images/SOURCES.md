# Device thumbnail sources

Every PNG here is a derivative of a freely licensed photograph. Each one was produced with
`dart run tool/prepare_device_image.dart <source> <output.png>`, which removes the plain
background, trims to the device, and fits it inside the avatar circle on a transparent 256 px
canvas. `tool/validate_json.dart` checks that the result is transparent and circle-safe.

Derivatives keep the original license. "Shows" names what the photo actually depicts when one
image serves several near-identical templates.
